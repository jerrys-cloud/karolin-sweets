# ריל פעילויות כריסמס לילדים

ריל אנכי 9:16 (1080×1920) באורך 18 שניות. ארבעה מסכים, כל אחד 4.5 שניות. כל הטקסט בערבית.

| קובץ | מה זה |
|---|---|
| `kids-christmas-reel.mp4` | **הסרטון המוכן**, מוכן להעלאה לאינסטגרם |
| `kids-christmas-reel.html` | האנימציה. קובץ אחד שעובד בכל דפדפן |
| `kids-template.html` + `build-kids.py` | המקור לעריכה. אחרי שינוי מריצים `python3 reel/build-kids.py` |

## הדרך הכי קלה
1. פותחים בטלפון את `https://karolinsweets.com/reel/kids-christmas-reel.mp4` ושומרים:
   - **אייפון:** שיתוף ⬆️ ← **שמור סרטון**
   - **אנדרואיד:** ⋮ ← **הורדה**
2. **העלאה:** אינסטגרם ← ➕ ← **Reel** ← בוחרים את הסרטון ← מוסיפים מוזיקה מהספרייה (♫).
3. **כיסוי:** בוחרים בתור Cover את מסך התאריך **30.11**.

## הקלטת מסך מהטלפון
1. 🔕 מצב טיסה, ונעילת המסך לאורך.
2. פותחים: `https://karolinsweets.com/reel/kids-christmas-reel.html?record`
3. **מסך מלא:** שיתוף או ⋮ ← **"הוסף למסך הבית"** ← פותחים מהקיצור.
4. **הקלטה:**
   - מפעילים הקלטת מסך. באייפון: מרכז הבקרה ← ⏺. באנדרואיד: החלקה מלמעלה ← Screen recorder.
   - **נוגעים פעם אחת במסך,** והריל מתחיל מההתחלה.
5. אחרי 18 שניות הריל נעצר. עוצרים את ההקלטה וחותכים ל-18 שניות בעורך של הגלריה.

## במחשב
פותחים את הקובץ ולוחצים **Clean ⤢**. הריל עובר למסך מלא נקי ומתחיל אחרי 1.2 שניות.
- **Windows:** ‏`Win + Alt + R`
- **Mac:** ‏`Cmd + Shift + 5`
- **אחרי ההקלטה:** חותכים את המלבן האנכי.

קיצורים: `Space` עצירה/המשך · `R` מההתחלה · `F` מסך מלא · `H` הסתרת כפתורים.

פרמטרים: `?record` (נקי, פעם אחת) · `?clean` (נקי, בלולאה) · `?bar=0` (בלי פס ההתקדמות).
